# Gentlemen's League

Private Liga-Seite für unsere Fantasy-Premier-League-Liga (ID 243508).

- `index.html`, `app.js`, `extras.js`, `comps.js` – die Seite
- `scripts/fetch.js` – holt die Daten von der FPL-API nach `data/data.json`
- `data/history.json` – echte Endtabellen vergangener Saisonen
- `data/competitions.json` – Spielplan Champions League & Cup
- `.github/workflows/update.yml` – aktualisiert täglich automatisch und veröffentlicht auf GitHub Pages

Nicht offiziell mit der Premier League oder Fantasy Premier League verbunden.
